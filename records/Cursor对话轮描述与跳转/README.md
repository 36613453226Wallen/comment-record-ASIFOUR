# Cursor 对话轮描述与跳转

| 文件 | 作用 |
| --- | --- |
| `Cursor对话轮描述与跳转.docx` | 每轮对话的目录表 + 分页问答 |

## 目录表

首页一张表，每轮一行：轮次、大概对话总结、权重、跳转。

跳转列只给**重要且大段**的轮次。显示词只有 `§n`，避免把表撑宽。点它跳到后文该书签。问答段末「回表」跳回目录。一般轮次这一格是「—」，没有链接。

表后面空行，再分页。问答从下一页开始。表变长占满首页时，问答仍从下一页起。

## 现在用的跳转

同一份 Word 里的书签。不打开 Cursor 网页，只在这份记录里跳到该轮问答的位置。

要跳到 Cursor 里某一条原话，书签做不到。那场对话的整场入口是云端对话页，不是每一轮一条独立链接。方法见这次对话里对「需求难点」的说明。
