## 两边怎么防混

1. **主语锁死**：A 栏只写 Empty，B/C 栏只写 AFor。
2. **禁写清单**：Empty 的栏里不许出现「AFor 说」；AFor 的栏里不许出现「所以 Empty 应该」。
3. **对照表是唯一见面处**：两边要对上或对不上，只能并排引用。
