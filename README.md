# 这场谈话的记录

这里只有 **一场** 对话记录，不是给以后多个前辈各准备一份的谈话工具箱。

文件就这一份：[records/2026-11-01-个人情况与经验给予.md](records/2026-11-01-个人情况与经验给予.md)

## 为什么用这一份，而不是模板 + 示例

上一版并排放了正式纪要、空白模板、虚构示例，看起来像在为「和很多人谈经验」做准备。那是多写了。

你要记的是已经发生的一场谈话：一边是你的个人情况，一边是对方给到的经验和建议。需要的是 **同一份里把两边隔开**，不是多套格式。

## 两边是怎么防混的

分节本身防不住。混在一起的句子通常长这样：

> 对方当年也是我现在这样，所以我应该听他的。

这一句把你的处境、对方的过去、对你的处方写成了同一件事。防混靠三条硬规则，都写在那一份纪要正文里：

1. **主语锁死**  
   「我的情况」只能写我；「对方经验 / 建议」只能写对方。谁的栏就用谁当主语。
2. **禁写清单**  
   我的栏里不许出现「对方说 / 他也遇到过 / 按他的经验」。  
   对方的栏里不许出现「我现在 / 我应该 / 所以我」。
3. **对照表是唯一见面处**  
   两边要对上或对不上，只能在对照表里并排引用，标明差在哪。不许在某一边的叙述里替另一边作解释。

先分开，再对照。对照是比较，不是把两段故事合成一段。
